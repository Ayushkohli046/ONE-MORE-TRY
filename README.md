# ONE-MORE-TRY

### Just one more run.

ONE More TRY is a neon-themed browser survival game build using HTML, CSS, and Javascript. Dodge falling obstacles, collect coins, grab shields, and try to beat your highest score.

I was working on this game last year, but back then, I didn't know much about JavaScript or GitHub. So, I decided to rebuild the game and rewrite the previous code to make it better. This is what I've been able to achieve so far. If there are any improvements I can make, please feel free to email me at **ayushkohli046@gmail.com**.

**Play Here:** [ONE MORE TRY](https://onemoretry-two.vercel.app/)

## Features 

- Keyboard controls
- Mobile touch controls
- Coin collection
- Shield power-ups
- High score tracking
- Increasing difficulty
- Pause and resume
- Neon visual effects
